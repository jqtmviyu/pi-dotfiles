# Pi Dotfiles

My pi coding agent configuration files.

## Extensions

### compact-tool-render
Compact tool render — displays tool calls as single-line rows.

### readonly-mode
Toggle read-only mode with `/readonly` command.

## Install

```bash
git clone https://github.com/jqtmviyu/pi-dotfiles.git /tmp/pi-dotfiles && cp /tmp/pi-dotfiles/extensions/*.ts ~/.pi/agent/extensions/
```
